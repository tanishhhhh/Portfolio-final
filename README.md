## 🚀 About The Project

This repository contains the source code for my personal portfolio website, designed with an **"Antigravity"** aesthetic. The interface features floating elements, physics-based interactions, and glassmorphism to reflect a modern, high-tech cybersecurity identity.

### Key Features
* **Physics-Based Animations:** Elements float and react to cursor movement using **Framer Motion**.
* **Glassmorphism UI:** Modern, translucent card designs.
* **Cybersecurity Focus:** dedicated sections for SIEM, Log Analysis, and Penetration Testing projects.
* **Fully Responsive:** Optimized for all devices.

## 🛠️ Tech Stack

* **Framework:** [Next.js 14](https://nextjs.org/) (App Router)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Animation:** [Framer Motion](https://www.framer.com/motion/)

## ⚡ Getting Started

To run this project locally, follow these steps:

### Prerequisites
* Node.js (v18.17.0 or higher)
* npm or yarn

### Installation

1.  **Clone the repository**
    ```bash
    git clone [https://github.com/tanishhhhh/Portfolio-final.git](https://github.com/tanishhhhh/Portfolio-final.git)
    ```
2.  **Navigate to the project directory**
    ```bash
    cd Portfolio-final
    ```
3.  **Install dependencies**
    ```bash
    npm install
    ```
4.  **Start the development server**
    ```bash
    npm run dev
    ```
5.  Open [http://localhost:3000](http://localhost:3000) to view it in the browser.
